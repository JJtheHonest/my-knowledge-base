# 校园网无感认证名额被占满：iPhone MAC 随机化

## 现象
校园网无感认证额度 5 台设备，实际只有 4 台常用设备（MacBook、Windows、两部 iPhone），却每隔一段时间名额被占满，且**只有 iPhone 被挤掉**，电脑从不掉线。

## 原理：认证系统靠 MAC 地址记设备
- 锐捷 / Dr.COM / H3C 等校园网无感认证，绑定的是**网卡 MAC 地址**，不是"物理设备"。
- 首次输账号密码 → 系统绑定「MAC ↔ 账号」→ 之后同 MAC 自动放行。
- 「5 台额度」= 允许绑定 5 个不同 MAC。**同一设备换了 MAC，在系统里就是一台新设备**。

## 为什么只有 iPhone 中招
iPhone 默认开启「私有 Wi-Fi 地址」（MAC 随机化），命中两个坑：
1. **MAC 定期轮换**（iOS 18+ 默认"轮换"档）：每隔一段时间换新随机 MAC，旧绑定不立即消失 → 同一部手机的多个历史 MAC 逐渐占满名额。
2. **每个 SSID 用独立随机 MAC**：连多个网络名（Campus / Campus-5G 等）时，一部手机就吃掉多个名额。

对比：macOS / Windows 默认不开 MAC 随机化，MAC 长期稳定，始终只占一个名额。

## 解决办法
1. 设置 → Wi-Fi → 点校园网右边 ⓘ → **私有 Wi-Fi 地址** → 选「关闭」（iOS 18+ 可选「固定」）。两部 iPhone 都要设。
2. 在校园网平台把现有无感认证名额**全部清除**（最后手动清一次）。
3. 让两部手机重新连接、认证一次。之后 MAC 固定，名额稳定占用，不再被挤。

补充：尽量固定连**同一个 SSID**，避免手机在多个网络名间乱连（iOS 按 SSID 记 MAC，不同 SSID 仍是不同 MAC，各占名额）。若关闭随机化后仍偶发，可能是学校侧绑定有过期策略，需找网络中心确认。

## Observations
- [原理] 校园网无感认证按网卡 MAC 地址绑定账号，而非物理设备 #认证机制
- [避坑] iPhone 私有 Wi-Fi 地址会定期轮换 MAC，导致同一设备占用多个认证名额 #MAC随机化
- [避坑] iOS 对每个 SSID 使用独立随机 MAC，连多个网络名会各占名额 #SSID
- [对比] macOS/Windows 默认不开 MAC 随机化，MAC 稳定只占一个名额 #跨平台
- [解决] 关闭或固定校园网的私有 Wi-Fi 地址即可让 MAC 稳定 #解决方案
